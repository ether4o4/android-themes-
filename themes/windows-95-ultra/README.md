# Windows 95 Ultra

**Status: In development**

Retro desktop graphics, Jazz-inspired teal and purple, platinum controls, and modern Android functionality.

## Collection

- Home and lock-screen artwork
- Theme Park palettes and icons
- Optional desktop-style widgets: Weather, System Monitor, Control Panel, Media Player, Notepad, Widget Explorer, Calendar, Task Manager, Network Monitor and Sound Mixer
- Experimental post-unlock animation

No replacement launcher or second authentication screen.

No verified APK has been released yet.
